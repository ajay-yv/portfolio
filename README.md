🔗 **Live Production URL**: [https://portfolio-ox7g.vercel.app/](https://portfolio-ox7g.vercel.app/)

---

## ✨ Features & Project Scope

*   **Interactive Particle Background**: Custom interactive canvas particle generator responding in real-time to focus positions and cursor repulsion physics.
*   **Mouse Spotlight & Glassmorphic Highlights**: High-performance gradient spotlight overlays that dynamically trace pointer coordinates.
*   **Animated Counter Stats**: Custom statistics counters counting up to record highlights, including VTU CGPA (8.77), flagship AI applications, and DSA problem indices.
*   **Skill Performance bars**: IntersectionObserver-driven CSS progress bars animating dynamically as navigation sections come into view.
*   **LeetCode & GitHub Metric Integration**: Live grid visualizer simulating GitHub commit matrices alongside LeetCode problem breakdown distributions.
*   **Direct QR Modal & Toast Engine**: Fast client-side links and clipboard copy triggers displaying custom toast alerts.

## 🏃 Local Development Instructions

### 📥 1. Clone the Project
```bash
git clone https://github.com/ajay-yv/portfolio.git
cd portfolio
```

### 🧑‍💻 2. Install Dependencies
```bash
npm install
```

### 🚀 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 📦 4. Build for Production
```bash
npm run build
```
Generates optimized target assets inside the `dist/` directory.
